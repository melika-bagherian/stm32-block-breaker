# 🎮 STM32 Block Breaker

یک بازی **Block Breaker / Arkanoid** توسعه‌یافته با **STM32 و Embedded C** که روی نمایشگر LCD 20×4 اجرا می‌شود.

در این پروژه، منطق بازی، کنترل بازیکن، برخورد توپ با بلوک‌ها، سیستم امتیاز و جان، منوی بازی و افکت‌های صوتی با استفاده از امکانات میکروکنترلر پیاده‌سازی شده‌اند.

---

## ✨ قابلیت‌ها

- منوی اصلی و بخش‌های مختلف بازی
- کنترل Paddle با دو روش:
  - 4×4 Keypad
  - Potentiometer

- حرکت و برخورد توپ با دیواره‌ها، Paddle و بلوک‌ها
- سیستم امتیازدهی
- سیستم Health / جان بازیکن
- High Score
- بلوک‌های ویژه
- نمایش وضعیت بازی روی LCD
- افکت‌های صوتی با Buzzer
- نمایش تاریخ و ساعت
- استفاده از کاراکترهای سفارشی LCD
- صفحه Game Over و امکان شروع مجدد بازی

---

## 🕹️ منطق بازی

بازی روی یک صفحه‌ی 20×4 اجرا می‌شود و شامل مجموعه‌ای از بلوک‌ها، Paddle و توپ است.

بازیکن باید با حرکت دادن Paddle، توپ را برگرداند و بلوک‌ها را از بین ببرد.

با برخورد توپ به بلوک‌ها، امتیاز افزایش پیدا می‌کند و در صورت از دست دادن توپ، Health بازیکن کاهش می‌یابد.

کنترل Paddle را می‌توان بین **Keypad** و **Potentiometer** تغییر داد.

## ⚙️ Peripherals & Technologies

این پروژه با استفاده از **Embedded C** و **STM32 HAL** توسعه داده شده است.

Peripheralهای مورد استفاده:

- **GPIO** — کنترل ورودی‌ها و خروجی‌ها
- **EXTI** — دریافت ورودی Keypad با Interrupt
- **ADC** — خواندن Potentiometer
- **Timer / PWM** — تولید صدا با Buzzer
- **RTC** — دریافت تاریخ و ساعت
- **LCD 20×4** — رابط کاربری و نمایش بازی
- **UART** — دریافت اطلاعات کاربر
- **Random Number Generation** — تولید موقعیت‌های تصادفی در بازی

## 🚀 اجرای پروژه

1. Repository را Clone کنید.
2. پروژه را با **STM32CubeIDE** باز کنید.
3. فایل `.ioc` را در صورت نیاز با STM32CubeMX بررسی کنید.
4. سخت‌افزار مورد نیاز را مطابق تنظیمات پروژه متصل کنید.
5. پروژه را Build کرده و روی میکروکنترلر Flash کنید.
